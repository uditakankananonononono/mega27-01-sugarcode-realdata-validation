\section{Module inventory and validation coverage}
sugarcode-ai contains 95 application modules and 32 bio/ libraries. 49 of these 127 have been checked against an independent reference on real data in this work (18 modules, 31 libraries). The rest are not yet validated. That does not mean they are wrong, only that no claim about them is made here. Validation status is a curated list tied to committed result files (manifests/module\_inventory.tsv, built by sweep/module\_inventory.py), not a keyword match.
